VLC filters, RTX VSR and DLSS 5 are different.

Live contrast, brightness, saturation and gamma controls work through VLC. Its optional driver super-resolution setting may use RTX VSR on supported NVIDIA hardware; this build does not verify driver execution. Neither is DLSS 5. No native DLSS 5 adapter, NVIDIA runtime or approved model is bundled.

GET STARTED

Three steps. No background service.

01

Install official VLC

Use 64-bit VLC 3.0.24 or newer in the 3.0 series from VideoLAN. VLC 4 has a different ABI and is not supported by this build.

VideoLAN website ↗
02

Run Shiny Player

Extract shiny-vlc-player-0.5.0-unsigned.zip from the build artifact and open ShinyVlcPlayer.exe. No administrator rights are needed.

Only run a package from a trusted source; compare the included checksum.

03

Choose your media

The standard VLC installation is detected. Otherwise use Media → Locate installed VLC. Open or drop a file, or explicitly enter a media-stream URL.

Selecting a VLC directory authorizes loading its native libraries and plugins.

IN THE PLAYER

Playback controls that matter.

Queues and repeat/shuffle. Seek, speed and A-B loops. Audio tracks, equalizer presets, external subtitles and timing offsets. Chapters, frame step, aspect, crop, deinterlace, fullscreen and displayed-frame PNG exports.

Support depends on the input and your installed VLC plugins. Advanced conversion, disc menus, capture and casting are available through Full VLC, which opens the original VLC interface separately and pauses Shiny playback.

EXTERNAL TREATMENT REVIEW

Keep the original in view.

Load an original local video, then Compare video to place an externally processed version beside it. The original supplies the only audio. Imported provenance is unverified, and synchronization is best-effort—not frame-exact.

Build from source and validation boundaries

Requires Windows x64, the Visual Studio C++ toolchain and CMake. See native/vlc-player for pinned headers, source notices and build instructions. Runtime binaries are installed separately, not redistributed.

Software CI validates real libVLC decoding and selected controls. It does not certify physical GPU/VSR performance, HDR, sound-device playback, full codec coverage or long-session stability. Native DLSS inference remains unimplemented; the browser Neural Lab is separately gated.
