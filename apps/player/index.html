THE RESEARCH PATH

Explicit local experiments.
Original playback preserved.

In the native DLSS-NR Research Studio, select Local research, inspect a compatible folder and acknowledge your authorization to use it. The worker validates that exact manifest again before loading the real OpenDLSS-NR graph.

Preparing a model does not certify it. User files are never silently added to the reviewed-model registry. The browser Neural Lab retains its separate reviewed-only policy.

Keep the experiment legible.

Adjust the graph's appearance controls.

Compare matched inputs, not unrelated moments.
Pause / Stop
Inspect a frame or release the worker.

This guide does not run inference in your browser.

Research support is not a production DLSS claim.

The release tests software playback, model intake, UI and installation. It does not establish trained-model output quality, vendor parity, temporal consistency, real-time performance or neural audio synchronization. Conventional VLC filters, RTX VSR requests and OpenDLSS-NR are different paths.

WINDOWS SETUP

One application. Separate choices.

01

Install or unpack

Download the setup executable or portable ZIP from the versioned release. Setup installs per user, adds shortcuts and supports uninstall. No administrator rights are required.

Build from source ↓
02

Choose the playback engine

Use official x64 libVLC 3.0.24+ in the 3.0 series. Setup can optionally download its pinned runtime from VideoLAN without modifying a system VLC installation. VLC 4 is not supported.

VideoLAN website ↗
03

Play first. Experiment second.

Open or drop a video. Cinema, subtitles and bookmarks work independently. Open the research studio only when you choose to test local data you are authorized to use.

The extension opens this guide; it does not install or launch native programs.

PLAYBACK WORKSPACE

The controls you reach for.

Reflowing toolbars and DPI-aware controls. Cinema and always-on-top. Queues, reordering, repeat and shuffle. Seek, speed, A–B loops, bookmarks and jump-to-time.

Audio output devices and equalizer presets. Audio/subtitle tracks and timing, external subtitles, chapters, frame step, aspect/crop/deinterlace and displayed-frame snapshots.

Full VLC opens the original separate application for advanced functions not reproduced here.

Check before you prepare.

Packaged worker and shaders beside the player.

Required Vulkan features. Use Check GPU; a brand name alone is insufficient.

Native 71-block manifest and stage files; 256 MiB stage budget.
Preview
33–512 pixels per axis, independent SDR frames and CPU transfers.
Build from source and validation boundaries

Requires Windows x64, the Visual Studio C++ toolchain, Windows SDK, CMake, Python 3, Git and Inno Setup 6. The script checks pinned dependencies and archive hashes.

powershell -File scripts/Build-Windows.ps1

Source is in native/vlc-player, native/nr-worker and docs/research-mode.md. Exact-commit browser-build, windows-build and vlc-player checks gate publication. Trained inference and physical GPU validation are separate requirements.

macOS and Linux native installers are not implemented. No models or NVIDIA DLLs are redistributed.
