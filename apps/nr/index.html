What this build can and cannot do

The bundled MIT reference implements the OpenDLSS-NR graph. It does not include NVIDIA weights. This build starts with an empty reviewed-model register, so neural inference is locked. A maintainer must establish model-use rights and independent correctness evidence, then add the exact manifest fingerprint through a reviewed repository change.

When that gate is satisfied, this lab supports serial live source processing in a dedicated worker. The worker retains GPU intermediates, drops obsolete results, and has a bounded watchdog. Stopping releases the worker and capture. No fake neural output is substituted.

The browser path is a reduced-resolution research experiment, not the planned native real-time backend. Windows-native neural integration, engine motion vectors, optical flow, temporal feedback, full-display overlays, HDR and frame generation remain separate work.

No source names, frames, model bytes, or browsing history are uploaded. Reports contain model fingerprints and processing metadata but omit source filenames.
